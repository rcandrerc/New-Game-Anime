# Regras do New-Game-Anime

- Jogo de teste com visual anime do André, separado do Quimera Sandbox. Site de teste: https://rcandrerc.github.io/New-Game-Anime/ — **sempre mande esse link no fim de cada atualização.**
- Os **arquivos originais** (Mixamo .fbx, VRoid .vrm, pacotes CC0) ficam no repositório privado **rcandrerc/New-Game-Anime-fontes**, nunca aqui (este repositório tem site público pelo GitHub Pages). Aqui só entram os personagens já convertidos (`personagens/*.glb`) e o que o jogo usa.
- **Antes de baixar algo novo**, confira o `INVENTARIO.md` do New-Game-Anime-fontes pra não duplicar. **Depois de baixar**, guarde lá e **atualize o `INVENTARIO.md`** (regras completas no CLAUDE.md de lá).
- Só use material livre pra uso comercial; registre a licença em `LICENCAS.md`.
- O André joga só no celular Android, **deitado** (paisagem): teste o layout em 904x407.
- Conversão de personagem: `tools/build_vrm.py` (veja `tools/LEIAME.md`).
